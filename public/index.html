Architecture

Four Independent Autonomous Agents

UNCOVER rejects monolithic single-prompt outputs. Research is partitioned across four specialized, decoupled AI agents that challenge, corroborate, and cross-examine each other's evidence.

AGENT 01

Research Agent

Discovery & Sourcing

Formulates precise multi-angle search queries, searches live indexed web sources via Tavily, extracts exact URLs and timestamps, and isolates granular factual claims.

  • Semantic query decomposition
  • Real-time Tavily search execution
  • Source authority & date extraction
  • Discrete factual claim structuring
AGENT 02

Fact-Checker

Verification & Corroboration

Rigorously tests each claim against the retrieved text corpus. Identifies supporting and contradicting citations, assesses certainty, and assigns categorical truth labels.

  • Multi-source cross-examination
  • Supporting & refuting quote isolation
  • Strict 4-tier status classification
  • Transparent verification rationales
AGENT 03

Conflict Analyst

Discrepancy Analysis

Compares claims across diverse outlets to expose contradictions, numerical discrepancies, differing baselines, and methodological divergence.

  • Contradictory premise detection
  • Statistical & metric divergence
  • Context & methodology scrutiny
  • Side-by-side claim confrontation
AGENT 04

Report Generator

Synthesis & Delivery

Transforms all verified evidence, conflict tables, and source records into an executive briefing dossier featuring live citations, copy, print, and PDF downloads.

  • Executive summary & key findings
  • Interactive clickable citations
  • Identified research limitations
  • PDF export & print readiness

Evaluation Standard

Strict Fact-Checking Taxonomy

Every isolated claim undergoes rigorous verification, categorizing statements into four explicit, verifiable conditions.

VERIFIED
Fully Corroborated

Directly confirmed by multiple reputable sources with concordant data, dates, and experimental context.

PARTIALLY VERIFIED
Conditional Accuracy

Core premise holds, but specific parameters, metrics, or nuances diverge or lack complete confirmation.

DISPUTED
Conflicting Evidence

Reputable sources present contradictory findings, clashing measurements, or incompatible conclusions.

UNVERIFIED
Insufficient Data

No primary empirical documentation or authoritative corroboration discovered across indexed records.
